# TELAS（TEikyo Life & Academic Support）

帝京大学 LMS（Blackboard Ultra）用的工具集：网站、油猴脚本、iOS App、Android App。
这个仓库只放 **App 的安装包**（[Releases](https://github.com/manjuu08/telas-release/releases)）和说明，源代码不公开。

> **非官方工具**，和帝京大学、Anthology（Blackboard）都没有关系。用的是学校网站自己调用的内部接口，学校那边改版后可能失效。请在遵守学校 IT 使用规定的前提下使用。
> 脚本和 App 都只在你自己的设备上运行，用你自己的账号登录学校的网站，作者收不到任何数据。

## 油猴脚本

装在浏览器里，打开 LMS 后左侧菜单多出四项。

**安装**：电脑装 Tampermonkey 或 Violentmonkey，iPhone / iPad / Mac 的 Safari 装 Userscripts，然后打开 <https://telas.manjuu.net/teikyo-bb.user.js> 安装（步骤见[首页](https://telas.manjuu.net/)）。之后自动更新；有新版本时左侧的 TELAS 项会出现红点。

- **一括ダウンロード**
  - 按学期选课程，扫描课程内容（文件夹、文件、附件、正文里的链接），勾选后批量下载；可以打包成一个 ZIP（iOS 默认打包）。
  - 每一项显示说明文字；可以显示已归档的课程。
  - 讲义视频（Mediasite）：列表里有「打开」链接，在播放页上可以直接下载 MP4。
- **問題演習**
  - 选课程和测验 / 作业，显示作答次数、剩余次数、说明。
  - 题目一键复制给 AI，粘贴 AI 的回答后自动解析、预览、保存答案；「提出…」确认后直接交卷（先保存，有一题保存失败就不交），交卷后显示得分和受付番号。
  - 支持的题型：单选、多选、匹配、判断、填空（多空）、数值、记述。记述题有自己的输入框。
  - 文本 / 文件作业也可以在面板里提交。
  - AI 的网址可以自己填，也可以填 App 的 URL scheme（如 `chatgpt://`），手机上直接打开 App。
  - 可以把这门课的资料一起分享给 AI：PDF 可以先转成纯文字的 Markdown（扫描版保持 PDF）；手机上弹出系统分享菜单，电脑上保存后拖进 AI 网页。
  - 不会自己新建作答（会消耗次数），开始作答前一定会确认。
- **お知らせ・課題**
  - 按学期（或单个课程）汇总 LMS 的公告和作业。
  - 作业显示截止时间、提交状态、得分、剩余作答次数，过期的标出来；可以只看未提交的。只读。
- **自動ログイン**
  - 在 LMS 的登录页自动填入学籍番号和密码并登录（可以设成只填不按、设置等待时间）。
  - 凭据只存在你自己的脚本管理器里；设置面板不会把已保存的密码放回输入框。
- 日本語 / English / 中文，浅色 / 深色。

## iOS App

原生 App（SwiftUI，**iOS 16 以上**，iPhone / iPad），不是网页套壳：App 自己登录 LMS 和 Campus Square、直接调用接口。

| 标签页 | 内容 |
|---|---|
| ホーム | 最近的事项（快截止且没交的作业、有效的 PC 预约）；公交拥挤（三个方向的摄像头）；PC 预约（Ist-Reserve：当天的コマ，座位图上按コマ上色、双指放大，点空座确认预约、可以取消）；蔦友館菜单；教员一览（八王子，可搜索、按所属筛选）；图书馆（见下）；今天的课 |
| 時間割 | 右上角切换周 / 月。周：Campus Square「休講・補講・教室変更参照」的课表（教室、教员、休讲・补讲・教室变更用颜色区分），左右滑换周。月：有课的日子和有作业截止的日子做标记，点日期看当天 |
| LMS | 按学期选课 → 课程内容 → 点文件下载并预览；已下载的文件左滑删除或分享；多选 / 全部下载、ZIP；讲义视频；「問題演習」（作答次数、开始 / 继续、作业说明、原生作答、复制给 AI、文本 / 文件 / 照片提交、把课程资料分享给 AI、交卷） |
| CampusSquare | 成绩（科目别，可按评价排序，导出 CSV）、学期别 GPA、毕业要件、出席（每次课的出欠和打刻时刻，可切换年度）、科目检索（时间割检索，带シラバス链接） |
| お知らせ | LMS 公告、作业（按截止排序）、Campus Square 掲示板（按日期新→旧，可搜索，附件在 App 里打开） |
| 設定 | 外观（跟随系统 / 浅色 / 深色）、头像（直接改 LMS 的头像）、账号、二次验证的密钥、保存位置、语言、已归档课程、AI 的网址 |

- 登录：学籍番号、密码，以及二次验证的**密钥**（只存在本机的钥匙串里）。Campus Square 用同一个账号以学生身份登录，验证码由密钥自动生成。
- 密钥的获取方法：打开 <https://teikyo.ex-tic.com/idm/user/mfa_setting>（统合认证设置）→ 先解除「アプリ認証」再重新设置 → 点「シークレットキーをコピー」→ 粘贴到登录画面。重新设置后旧的密钥失效，验证器 App 也要登记新的。
- 下载的文件默认在「文件」App →「我的 iPhone」→ TELAS，按「课程 / 文件夹 / 文件名」存放；设置里可以换成别的文件夹。
- **图书馆**（ホーム的「図書館」格子，读的是图书馆 OPAC opac.teikyo-u.ac.jp）：
  - 蔵書検索（书名・作者・关键词，可以继续读下一页）；不搜索时显示貸出ランキング / アクセスランキング。
  - 点一本书：所有馆藏（所蔵館・配置場所・請求記号・状態，贷出中的显示返却予定日和予约数）和书目详情；「OPAC で開く」去网页预约。
  - 利用状況：用和 LMS 相同的学籍番号・密码登录图书馆（「統合認証IDをお持ちでない方」，不走统合认证），显示图书馆的通知、借着几册・有没有逾期、预约、复印 / 借阅 / 购买委托，以及贷出履历。
  - 电子图书馆（Teikyo Digital Library）：在浏览器打开。
  - 借着的书的列表、续借、预约还要在 OPAC 网页上操作。
- 读过的内容（课程、文件列表、公告和作业、成绩、出席、课表、掲示板）会保存，下次打开先显示上次的内容，同时在后台更新。

**安装**：IPA 没有签名，用 **Sideloadly**（电脑 + USB）或 **AltStore / SideStore** 以自己的 Apple ID 签名安装。免费 Apple ID 签名的 App 7 天后过期，要重新签（AltStore 可以自动续签）。iOS 16 以后要在「设置 → 隐私与安全性」里打开开发者模式。

## Android App

原生 App（Jetpack Compose，**Android 8.0 以上**），功能和 iOS 版相同：ホーム（最近的事项、公交拥挤、PC 预约、蔦友館菜单、教员一览、图书馆、今天的课）、時間割、LMS（课程内容、下载、問題演習）、CampusSquare（成绩・GPA・毕业要件・出席・科目检索）、お知らせ（公告、作业、掲示板）、设置（外观、语言、账号、二次验证的密钥、保存位置、已归档课程、AI 的网址）。登录同样需要学籍番号、密码和二次验证的密钥（取法同上）。

- 保存位置：设置里选一个文件夹后，下载的资料和讲义视频也会复制到那里；App 里的「下载的文件」随时都能打开。

- 账号用 Android Keystore 的密钥加密后保存在本机，不进备份。
- **安装**：下载 APK 打开，按提示允许「安装未知应用」。每个版本用同一个签名，新版本可以直接覆盖安装，数据保留。

## 日本語

帝京大学 LMS（Blackboard Ultra）のためのツール群です。このリポジトリには **アプリのインストールファイル**（[Releases](https://github.com/manjuu08/telas-release/releases)）と説明だけを置いています（ソースコードは非公開）。非公式ツールで、帝京大学・Anthology（Blackboard）とは関係ありません。

- **Web サイト** <https://telas.manjuu.net>：トップはダウンロードページ（.ipa・.apk・スクリプト）。右上のメニューから バス停混雑状況（`/bus`）・蔦友館 メニュー（`/choyukan`）・教員一覧（八王子、`/teachers`）。
- **ユーザースクリプト**（1.0）：LMS の左メニューに 一括ダウンロード・問題演習・お知らせ・課題・自動ログイン設定 を追加。Tampermonkey / Violentmonkey（PC）、Safari の Userscripts（iPhone / iPad / Mac）。
- **iOS アプリ**（1.1、iOS 16 以上）：ホーム（直近の予定・バス混雑・PC 予約・蔦友館メニュー・教員一覧・図書館・今日の授業）、時間割、LMS（教材・問題演習）、CampusSquare（成績・GPA・卒業要件・出席・科目検索）、お知らせ（お知らせ・課題・掲示板）。IPA は署名なしなので Sideloadly / AltStore などでサイドロードしてください。
- **図書館**（1.1〜）：OPAC の蔵書検索・貸出 / アクセスランキング・所蔵と状態・利用状況と貸出履歴（LMS と同じ学籍番号・パスワードでログイン、統合認証は使いません）・電子図書館へのリンク。予約・延長は OPAC の Web ページで。
- **Android アプリ**（1.1、Android 8.0 以上）：iOS 版と同じ機能。APK を開いて「提供元不明のアプリ」を許可してインストール。新しい版は上書きインストールできます。
